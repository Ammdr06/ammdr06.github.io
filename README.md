# Mahadeer A — Academic Portfolio

Academic portfolio of Mahadeer A, a doctoral researcher in Mathematics at SRM Institute of Science and Technology.

Theoretical research on partial and Watson–Crick partial Petri net languages is presented separately from applied work on image segmentation and image encryption.

## Website

GitHub Pages address: https://ammdr06.github.io/

Publishing source: the **main** branch, **/(root)** folder. No build or dependency installation is required. The `.nojekyll` file preserves this static website as supplied.

## Editing

- `index.html`: biography, research directions, academic profile, and contact information.
- `app.js`: publication metadata, search, filters, and citation behavior.
- `styles.css`: responsive navy, ivory, and muted gold theme.
- `assets/mahadeer-faculty-cv.pdf`: faculty application CV.
- `assets/mahadeer-postdoctoral-cv.pdf`: postdoctoral application CV.
- `assets/mahadeer-publications.bib`: downloadable bibliography.

Fonts are served locally; their licensing information is in `assets/font-license.txt`. No photograph or signature was extracted from the CVs. The PDF downloads are the original supplied files.

After editing the site files, commit to `main`; GitHub Pages publishes updates automatically when configured with the publishing source above.
